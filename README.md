## The line

> I'm stuck behind glass, but if you press B4, I'll drop something sweet. Fair warning: it's me.

One line, 94 characters. `main.py` writes it to `entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR` (then `/output` when it exists, then the folder holding the program). No network, no randomness, no clock: two runs produce byte-identical output.
